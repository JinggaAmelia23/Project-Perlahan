# Project-Perlahan
1. Buka terminal di VS Code
Buka VS Code, lalu pilih menu Terminal → New Terminal.
2. Tentukan folder penyimpanan
Misalnya, kamu ingin menyimpan project di folder htdocs milik XAMPP. Ketik perintah berikut:
cd C:\xampp\htdocs

3. Clone repository GitHub
Salin perintah ini ke terminal, lalu tekan Enter.
git clone https://github.com/JinggaAmelia23/Project-Perlahan.git

Tunggu sampai proses selesai.
4. Masuk ke folder project
cd Project-Perlahan

Lihat file yang ada di dalamnya:
dir

5. Buka project di VS Code
code .

Sekarang project Project-Perlahan akan terbuka di VS Code.
Jika muncul error
Kalau muncul pesan git is not recognized, pastikan Git sudah terinstal. Cek dengan perintah:
git --version
